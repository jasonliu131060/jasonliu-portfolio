# Jason Liu Engineering Portfolio

Static engineering portfolio, published with GitHub Pages from the `docs/` folder on `main`.

Live site: https://jasonliu131060.github.io/jasonliu-portfolio/

## Local preview

```bash
python3 -m http.server 4173 --directory docs
```

## Updating

Edit files in `docs/`, then commit and push to `main`. GitHub Pages republishes automatically.

The site is marked `noindex` for direct sharing with recruiters. That discourages search indexing but does not make the site private.
